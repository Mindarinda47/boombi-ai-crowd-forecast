# 붐비 — 부산 AI 혼잡 예보

부산 주요 권역의 시간대별 혼잡 가능성을 예측하고, 근거와 대체 장소를 함께 제공하는 1인 개발 프로젝트입니다.

이 저장소는 2026년 넥슨 넥토리얼 지원 포트폴리오를 위한 비공개 선별본입니다. 제출 자료, 빌드 결과, 임시 파일과 로컬 환경값은 제외했습니다.

## 핵심 정보

- 형태: 1인 프로젝트
- 개발 기간: 약 3일
- 기술: TypeScript, Next.js 호환 구조, React, Supabase PostgreSQL, Drizzle ORM, Cloudflare Worker
- 담당: 기획, 데이터 모델, 예측 규칙, AI 연동, UI, 테스트, 배포 구조

## 주요 기능

- 부산 42개 권역의 8일·시간대별 혼잡 예보
- 행사, 평시 수요, 검색 관심도, 날씨와 달력 조건 결합
- 비정형 행사 정보의 AI 구조화
- AI 제공자 실패 시 fallback 처리
- 상위 혼잡 알림과 날짜·지역 비교
- 지도 마커와 대체 장소 추천
- 조건 변경 시나리오 분석
- 예측 점수의 근거와 신뢰도 표시

## 설계 원칙

AI는 행사 공지처럼 구조화되지 않은 입력을 정리하는 역할을 담당합니다. 최종 혼잡 점수는 재현성과 비용 통제를 위해 규칙 엔진이 계산합니다. 서비스가 제공하는 값은 실제 현장 인원 수가 아니라 의사결정을 돕기 위한 혼잡 가능성 점수입니다.

## 검증

- 추적된 테스트 파일 2개
- 자동화 테스트 39개
- 예측 엔진, 렌더링 결과, fallback, 시나리오와 데이터 검증 포함

```bash
pnpm install
pnpm test
pnpm build
pnpm dev
```

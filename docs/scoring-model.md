# 점수 모델

이 문서는 [`domain/forecast/score.ts`](../domain/forecast/score.ts)의 `forecast-v1.3.0` 구현을 기준으로 합니다. 점수는 실제 인원수가 아니라 같은 기준에서 지역·날짜·시간대를 비교하기 위한 0~100 범위의 상대값입니다.

## 계산식

```text
최종 점수 = clamp(
  평시 기준 × 0.60
  + 검색 추세 × 0.25
  + 달력 조건 × 0.15
  + 행사 영향 × 0.25
  + 날씨 보정
  + 인접 행사 보정,
  0, 100
)
```

| 요소 | 입력 범위 | 최종 기여 | 의미 |
| --- | --- | --- | --- |
| 평시 기준 | 0~100 | 최대 60점 | 권역·시간대의 평상시 수요 |
| 검색 추세 | 0~100 | 최대 25점 | 최근 3일과 이전 7일의 관심도 변화 |
| 달력 조건 | 0~100 | 최대 15점 | 평일·주말·공휴일·방학 패턴 |
| 행사 영향 | 0~100 | 최대 25점 가산 | 규모와 한정 상품·선착순·시간 집중 등 |
| 날씨 보정 | -12~12 | 그대로 가산·차감 | 실내·야외 장소에 다른 방향으로 적용 |
| 인접 행사 보정 | 0~10 | 그대로 가산 | 주변 행사의 파급 효과 |

행사 영향은 평시·검색·달력의 기본 비중 합계와 별도인 보너스입니다. 전체 합계가 100을 넘거나 0보다 작으면 최종 단계에서 범위를 제한합니다.

## 계산 예시

자동화 테스트에서는 다음 입력을 사용해 결과를 고정했습니다.

```text
평시 60, 행사 80, 검색 50, 달력 70, 날씨 +4, 인접 행사 +3
= 36 + 20 + 12.5 + 10.5 + 4 + 3
= 86점
```

## 행사 영향

행사 규모의 기본값에 수요 집중 신호를 더합니다.

- 규모: 소형 20, 중형 45, 대형 70, 초대형 90, 미확인 35
- 한정 상품, 선착순, 번호표, 무료 입장, 전국 단위 관심, 시작 시각 집중을 추가 반영
- 여러 행사가 겹치면 가장 큰 영향은 전부 반영하고 나머지는 각각 35%만 더해 과도한 단순 합산을 방지

장기간 여러 지역에서 열리는 행사인데 세부 개최일이 없으면 자동으로 점수에 넣지 않고 확인 대상으로 분리합니다.

## 검색 추세와 날씨

- 검색 추세는 최근 3일 평균과 이전 7일 평균의 비율을 구간화하고 월간 고점 여부를 추가합니다.
- 이전 검색 기준값이 없으면 중립값 45를 사용합니다.
- 강수 확률 60% 이상이면 실내 수요는 높이고 야외 수요는 낮춥니다.
- 강수량 15mm 이상, 폭염과 강풍에는 보정 폭을 더 크게 적용합니다.

## 위험 단계

| 점수 | 단계 |
| --- | --- |
| 0~34 | 여유 |
| 35~54 | 보통 |
| 55~74 | 혼잡 |
| 75~89 | 매우 혼잡 |
| 90~100 | 극심 |

경계값은 [`forecast-engine.test.mjs`](../tests/forecast-engine.test.mjs)에서 각각 검증합니다.

## 신뢰도는 별도로 계산합니다

혼잡 점수와 신뢰도는 같은 값이 아닙니다. [`confidence.ts`](../domain/forecast/confidence.ts)는 공식 출처 품질, 평시 데이터 품질, 검색·날씨 데이터 품질과 최신성을 별도로 조합해 `high`, `medium`, `low`로 표시합니다.

## 한계

- 실제 인원 계측값이 아닙니다.
- 입력 데이터의 최신성과 정확도에 영향을 받습니다.
- 돌발 사고나 미수집 행사는 반영되지 않을 수 있습니다.
- 충분한 사후 관찰 전에는 예측 적중률을 제시하지 않습니다.

# 점수 모델

실제 구현 코드에서 평시 기준 점수, 검색 추세, 달력 조건을 조합해 기본 점수를 만들고 행사 영향도를 추가합니다. 최종 값은 허용 범위로 제한합니다.

- 평시 기준 비중: 60
- 검색 추세 비중: 25
- 달력 조건 비중: 15
- 행사 영향: 조건에 따라 최대 25를 추가

행사 영향은 기본 비중 합계와 별도로 적용되는 보너스입니다. 초기 제출 문서에 남아 있는 다른 비율은 실제 구현과 일치하지 않으므로 포트폴리오에서는 사용하지 않습니다.

## 한계

- 실제 인원 계측값이 아닙니다.
- 입력 데이터의 최신성과 정확도에 영향을 받습니다.
- 점수는 상대적인 혼잡 가능성과 의사결정 근거를 제공합니다.
